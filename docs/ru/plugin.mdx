`comfyui-mcp` — это не просто MCP-сервер: он поставляется как полноценный
**плагин Claude Code**. Установка плагина даёт Claude экспертные,
модельно-специфичные знания о ComfyUI, чтобы он выбирал правильный сэмплер,
CFG, разрешение и файлы моделей без проб и ошибок.

```bash
# In Claude Code
/plugin marketplace add artokun/comfyui-mcp
/plugin install comfy
```

## 39 ИИ-скиллов — и их становится больше

Скиллы — это курируемые документы знаний, которые Claude подгружает по
запросу. Каждое семейство моделей получает параметры генерации, графы узлов,
курируемые URL скачивания моделей и подсказки по режимам отказа:

| Скилл | Чему учится Claude |
|---|---|
| `flux-txt2img` | Flux.1 Dev/Schnell + Flux 2 Klein — ловушки BF16 vs FP8, разводка dual-CLIP, выбор VAE |
| `wan-t2v-video` / `wan-flf-video` | WAN 2.x text-to-video и воркфлоу first-last-frame |
| `wan-scail-replacement` | Замена персонажа в видео SCAIL-2 — правило reference-framing→scale, настройка и ловушки композитинга |
| `ltxv2-video` | LTX-2.3 (и LTX-2 19B) — GGUF UNet, distilled-модель, LoRA управления камерой, двухступенчатый апскейл, фикс kornia |
| `qwen-txt2img` / `qwen-image-edit` | Генерация Qwen-Image и редактирование по инструкции |
| `z-image-txt2img` | Воркфлоу Z-Image Turbo |
| `ideogram-ultra` | Ideogram 4 — открытые веса text-to-image, area prompting, логотипы / постеры / читаемый текст |
| `ernie-image` | ERNIE-Image — быстрый text-to-image, точный многоязычный текст, работает на менее чем 8 ГБ VRAM |
| `anima-base` | ANIMA 1.0 — ~2B аниме/иллюстрация, теги Danbooru + естественный язык, аниме-инпейнтинг, менее 6 ГБ VRAM |
| `anima-lora-trainer` | Обучение своих аниме-LoRA — Gradio-тренер kohya `sd-scripts`, менее 6 ГБ VRAM |
| `ai-toolkit-trainer` | Обучение своих LoRA WAN 2.2 + Z-Image (люди / стили / движение) — ostris AI-Toolkit, локально или на RunPod |
| `installer-packs` | Использовать, собирать и выводить установочные пакеты в одну команду — и приглашать пользователей приносить новые пакеты апстрим |
| `panel-node-pack-sync` | Держать пакет узлов боковой панели в шаге с оркестратором после обновления — обнаружение рассинхрона версий, пин версии, о котором предупреждают, а не перезаписывают, и синхронизация, чей результат перечитывается с диска |
| `model-compatibility` | Какая пара VAE/CLIP/text-encoder к какой архитектуре — причина №1 сломанных воркфлоу |
| `model-registry` | Курируемые URL скачивания + целевые каталоги для каждой модели, на которую ссылаются скиллы — растёт с каждым релизом |
| `civitai` | Нативный цикл Civitai discovery → локальное скачивание/разводка/генерация через встроенный `download_model` `action:"search_civitai"` (без ключа, без лишнего сервера); официальный [Civitai MCP](https://mcp.civitai.com/mcp) — необязательное дополнение поверхности сообщества, не бандлится |
| `comfyui-core` | Очередь, история и семантика API |
| `comfyui-node-registry` | Авторство + публикация пакетов кастомных узлов в Comfy Registry |
| `comfyui-frontend-extensions` | Авторство расширений фронтенда v1/v2 (вкладки боковой панели, виджеты) |
| `rgthree` | Настройка rgthree-comfy — переключатели групп Fast Groups Bypasser/Muter (узлы только фронтенда, которых нет в `/object_info`, задаются через PROPERTIES узла, не виджеты), стек Power Lora Loader, шины Context |
| `director` | Режиссура многокадровых сцен для видеоконвейеров |
| `prompt-engineering` | Промптинг под архитектуру (естественный язык vs теги) |
| `troubleshooting` | OOM, отсутствующие узлы, дрейф версий — деревья диагностики |
| `comfyui-launch-flags` | Матрица флагов запуска VRAM/attention/cache/perf — `--reserve-vram`, `--novram`+`--cache-none`, `--use-sage-attention` vs `--use-pytorch-cross-attention` (Z-Image), плюс заметки по стеку ускорения Blackwell/RTX 5000 |

Новые скиллы появляются с каждым релизом — генерируются из популярных пакетов
реестра встроенным инструментом `list_packs` (`action: "generate_skill"`),
затем курируются человеком.

**Попробуйте знания, ничего не подключая** — каждый скилл это обычный
markdown-файл, полезный сам по себе. Самый широко применимый —
[`prompt-engineering`](https://github.com/artokun/comfyui-mcp/blob/main/plugin/skills/prompt-engineering/SKILL.md)
— лимит CLIP в 77 токенов и нарезка `BREAK`, синтаксис весов и стратегия по
архитектуре (почему Flux хочет естественный язык и без негативного промпта,
а SD1.5 хочет теги). Прочитайте в браузере или вставьте в контекст любого
агента как системный промпт — ни ComfyUI, ни MCP, ни установка не нужны.
Когда подключите полный плагин, агенты подгружают те же файлы автоматически
(`list_packs` with `action: "skill_read"`).

### Поиск Civitai — встроенный

`download_model` `action:"search_civitai"` ищет на Civitai нативно (публичный
REST API, без ключа, без лишнего сервера): ключевое слово + фильтры `types` +
`base_models` («**Flux** LoRA»), по умолчанию только SFW, и каждый хит
возвращает `model_version_id`, который `action:"download_civitai"` берёт
напрямую — плюс **триггер-слова** модели для промпта. Поскольку это
полноценный инструмент, он работает на **каждом бэкенде**, включая небольшие
локальные модели за компактным роутером. Скилл `civitai` учит полную передачу
discovery → download → generate.

**Необязательный API-ключ.** Для поиска он не нужен. `CIVITAI_API_TOKEN`
открывает gated/early-access скачивания и gated результаты поиска — одна
переменная питает и поиск, и скачивание.

**Необязательно: официальный Civitai MCP.** Для поверхности сообщества за
пределами search→install (просмотр примеров изображений + их параметров
генерации, публикация, коллекции) подключите [официальный удалённый сервер](https://mcp.civitai.com/mcp)
Civitai — больше не бандлится автоматически, добавьте один раз:

```bash
claude mcp add --transport http civitai https://mcp.civitai.com/mcp \
  --header "Authorization: Bearer YOUR_CIVITAI_API_KEY"
```

## 11 слэш-команд

`/comfy:gen` (генерация по промпту), `/comfy:debug` (диагностика упавшего
воркфлоу), `/comfy:install` (установка пакетов узлов), `/comfy:viz`
(воркфлоу → Mermaid), `/comfy:batch`, `/comfy:compare`, `/comfy:convert`,
`/comfy:gallery`, `/comfy:recipe`, `/comfy:director`, `/comfy:node-skill`.

## 4 автономных агента

- **comfy-explorer** — глубоко ныряет в исходники пакета узлов, чтобы
  задокументировать его
- **comfy-researcher** — постановка задачи → ранжированные рекомендации пакетов
- **comfy-debugger** — ищет корневую причину упавших воркфлоу по истории + логам
- **comfy-optimizer** — настройка VRAM и скорости под данный GPU

## Боковая панель — без API-ключей

<Note>
  Боковая панель поставляется своим пакетом, **в Comfy Registry и в
  ComfyUI-Manager как `comfyui-agent-panel`** — найдите её там и выберите
  **Latest**, не Nightly. Полное руководство: [Боковая панель](/docs/ru/panel).
</Note>

Боковая панель [comfyui-mcp-panel](https://github.com/artokun/comfyui-mcp-panel)
запускает автономного агента на вашей **подписке Claude** (без потокенной
оплаты API). Установите пакет, откройте вкладку Агент и нажмите
**«Подключить»** — по запросу стартует [оркестратор панели](/docs/ru/configuration);
попросите изображение, воркфлоу или правку — и он работает с вашим ComfyUI.

## Хуки

Три хука держат сессии генерации собранными: **предполётные проверки VRAM**
перед постановкой воркфлоу в очередь, **уведомления о завершении задания** и
**предупреждения о сохранении** перед разрушительными операциями.
