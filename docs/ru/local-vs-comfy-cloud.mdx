Если вы выбираете между официальным агентским инструментарием Comfy-Org и этим
проектом, коротко: **они решают разные задачи** — и для немалого числа людей
официальный вариант правильный. Эта страница честно раскладывает оба, чтобы вы
выбрали один раз и пошли дальше.

<Note>
Comfy-Org выпускает быстро, и статусы ниже — на **июль 2026**. Проверьте
[docs.comfy.org/agent-tools](https://docs.comfy.org/agent-tools) на текущее
состояние, прежде чем считать что-либо из этого окончательным.
</Note>

## Ответ в одну строку

**Нет локального GPU или хотите нулевую настройку?** Берите Comfy Cloud. Это
first-party, это поддерживает команда, которая строит ComfyUI, и вам не нужно
думать о драйверах, VRAM и скачивании моделей.

**Уже гоняете ComfyUI на своей машине?** Для этого и существует этот проект.
GPU уже оплачен, модели уже на диске, а подписка Claude или ChatGPT уже
покрывает рассуждение.

## Что предлагает Comfy-Org

Страница [Agent Tools](https://docs.comfy.org/agent-tools) у Comfy-Org
перечисляет три релевантных продукта:

| Продукт | Что это | Статус (июль 2026) |
|---|---|---|
| **Comfy Cloud MCP** | Размещённый MCP-сервер; генерация идёт на GPU Comfy Cloud | публичная бета |
| **Comfy In-App Agent** | Агент в чате внутри Comfy Cloud, который собирает и правит ваш граф | закрытая альфа |
| **Comfy Local MCP** | Официальный локальный MCP-сервер, управляющий вашей установкой ComfyUI | закрытый тест; публично пока недоступен |

Comfy Cloud MCP действительно хорош в том, что делает: выставляет движок
ComfyUI через MCP, входит по OAuth из Claude Code, Claude Desktop и Codex и
даёт управляемый доступ к моделям вроде Kling, Veo, Seedance, Flux и
ElevenLabs без собственного GPU.

## Что предлагает этот проект

`comfyui-mcp` — это MCP-сервер плюс агент боковой панели, который управляет
**вашей** установкой ComfyUI — локальной, в LAN, на VPS или RunPod. 37
MCP-инструментов, 39 скиллов под конкретные модели и агент панели, который
правит живой граф на естественном языке.

Структурная разница — **откуда берётся рассуждение**. Этот проект не привязан
к провайдеру: те же инструменты и та же панель работают на Claude, ChatGPT,
Gemini, Grok или Kimi по подписке, которую вы уже платите, на любом
OpenAI-совместимом эндпоинте или на бесплатной локальной модели через
Ollama, LM Studio или llama.cpp — без аккаунта и без исходящей сети вообще.

## Бок о бок

| | Comfy Cloud (In-App Agent / Cloud MCP) | comfyui-mcp |
|---|---|---|
| Генерация идёт на | GPU Comfy Cloud | Ваш GPU (или ваш VPS / под RunPod) |
| Нужен аккаунт Comfy | Да | Нет |
| Полностью офлайн | Нет | Да, с локальной моделью |
| Модель рассуждения | Даёт сервис | **Ваша** — любая LLM, включая бесплатную локальную |
| Модель стоимости | Облачные кредиты | Ваша существующая подписка или $0 локально |
| Изображения/промпты покидают машину | Да | Только если вы сами выберете размещённую LLM |
| Управляет кастомными узлами и файлами моделей | Н/Д (управляемая среда) | Да — ставит узлы, скачивает модели |
| Доступность | Cloud MCP публичная бета; агент закрытая альфа | Доступно сейчас |
| Официальная поддержка | Да | Проект сообщества |

## Выбирайте Comfy Cloud, если…

- У вас нет GPU или он слишком мал для нужных моделей
- Хотите, чтобы работало без настройки и без обслуживания
- Предпочитаете покупать кредиты, а не возиться с CUDA, VRAM и чекпоинтами
- Команда уже на Comfy Cloud, и вы хотите одного вендора и один счёт
- Хотите официальную поддержку от тех, кто строит ComfyUI

Это хорошие причины. Если несколько из них про вас — хватит читать и идите
в [Comfy Cloud](https://comfy.org/): вам будет лучше.

## Выбирайте comfyui-mcp, если…

- **У вас уже есть GPU.** Вы за него заплатили; облачные кредиты — второй
  счёт за вычислительные ресурсы, которые вам уже принадлежат.
- **Ваша работа не может покинуть машину.** Клиентский материал под NDA,
  лицензированные обучающие данные, всё, что нельзя загрузить. С локальной
  моделью ничего не уходит.
- **Хотите использовать LLM-подписку, которая у вас уже есть.** План Claude
  или ChatGPT уже покрывает рассуждение — без второго счётчика для агента.
- **Хотите бесплатно или хотите офлайн.** Ollama, LM Studio и llama.cpp
  работают без аккаунта и без сети. См. [Локальные LLM](/docs/ru/local-llms).
- **Ваша установка и есть смысл.** Ваши кастомные узлы, ваши LoRA, ваша
  коллекция чекпоинтов. Агент [ставит узлы и скачивает модели](/docs/tools/models)
  в ту установку, которой вы реально пользуетесь.
- **Хотите выбирать модель.** Разные LLM лучше в разном; [LLM Arena](/docs/ru/arena)
  оценивает их на настоящих задачах ComfyUI, чтобы выбирать по фактам. См.
  [Бэкенды](/docs/ru/backends).

## «Официальный локальный MCP не сделает это лишним?»

Честный вопрос, и на него стоит ответить прямо, а не притворяться иначе.

Comfy Local MCP — это **официальный драйвер для локальной установки**, и
когда он выйдет, он будет хорошим. Но это другой слой, чем этот проект: он
подключает агента к ComfyUI, тогда как `comfyui-mcp` ещё приносит самого
агента, нейтральный к провайдеру бэкенд, который гоняет его на одиннадцати
провайдерах и локальных рантаймах, UI боковой панели, скиллы под модели и
управление узлами/моделями.

Честное прочтение: если вам нужно только «пусть Claude Code говорит с моим
локальным ComfyUI», официальный инструментарий это в итоге покроет, и вам,
вероятно, стоит им пользоваться. Если вы хотите принести свою модель —
включая бесплатную локальную — и чтобы агент жил внутри ComfyUI и сам
управлял установкой, вот пробел, который этот проект заполняет.

Они ещё и сочетаются. Этот проект тоже может целиться в Comfy Cloud
(задайте `COMFYUI_API_KEY` — см. [Развёртывание в облаке](/docs/ru/cloud-deployment)),
так что одна конфигурация покрывает локальную установку, коробку в LAN, VPS
и Comfy Cloud.
