**ComfyUI MCP** — это **локальная по умолчанию, изначально агентная плоскость управления** для
[ComfyUI](https://github.com/comfyanonymous/ComfyUI): [MCP](https://modelcontextprotocol.io)-сервер
и плагин Claude Code. Он подключает вашего ИИ-ассистента к работающему экземпляру ComfyUI —
**локальному**, **удалённому** или **[Comfy Cloud](https://cloud.comfy.org)**, — чтобы вы могли
генерировать изображения, видео и аудио, запускать и создавать воркфлоу, управлять моделями и
кастомными узлами и управлять сервером — всё это на естественном языке. Это не тонкий мост
«промпт → изображение», а полноценный агент, который работает с ComfyUI за вас.

## Область применения: локально, удалённо или Comfy Cloud

`comfyui-mcp` — это MCP от сообщества для **локального** и **удалённого** ComfyUI, и это основной
сценарий (установки на Mac/Linux/Windows, RunPod, VPS, LAN и т. д.).

Для пользователей **Comfy Cloud** у Comfy-Org есть [официальный агентский инструментарий](https://docs.comfy.org/agent-tools) — Comfy Cloud MCP (публичная бета) и Comfy In-App Agent (закрытая альфа), — который поддерживает команда Comfy и который работает на Comfy Cloud. Если у вас нет GPU или вы хотите обойтись вообще без настройки, используйте его ([сравнение бок о бок](/docs/local-vs-comfy-cloud)). В `comfyui-mcp` также есть облачный режим от сообщества (`COMFYUI_API_KEY`), так что один MCP может работать со всеми тремя вариантами развёртывания из одной конфигурации — выберите тот, который подходит вашему рабочему процессу.
