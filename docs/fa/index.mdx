**ComfyUI MCP** همان **سطح کنترلِ محلی‌محور و بومیِ عامل** برای
[ComfyUI](https://github.com/comfyanonymous/ComfyUI) است — یک سرور
[MCP](https://modelcontextprotocol.io) و افزونهٔ Claude Code. دستیار هوش مصنوعی شما را به یک نمونهٔ
در حال اجرای ComfyUI وصل می‌کند — **محلی**، **از راه دور**، یا
**[Comfy Cloud](https://cloud.comfy.org)** — تا بتوانید تصویر، ویدیو و صدا تولید کنید، گردش‌کارها را
اجرا و تألیف کنید، مدل‌ها و گره‌های سفارشی را مدیریت کنید و سرور را کنترل کنید؛ همهٔ این‌ها با زبان
طبیعی. این یک پل نازکِ پرامپت‌به‌تصویر نیست — یک عامل کامل است که ComfyUI را به‌جای شما می‌گرداند.

## دامنه: محلی، از راه دور، یا Comfy Cloud

`comfyui-mcp` همان MCP جامعه‌محور برای ComfyUI **محلی** و **از راه دور** است — هدف اصلی همین است
(نصب‌های Mac/Linux/Windows، RunPod، VPS، شبکهٔ محلی و مانند آن).

برای کاربران **Comfy Cloud**، تیم Comfy-Org [ابزار عامل رسمی](https://docs.comfy.org/agent-tools) عرضه می‌کند — Comfy Cloud MCP (بتای عمومی) و Comfy In-App Agent (آلفای خصوصی) — که تیم Comfy آن‌ها را نگهداری می‌کند و روی Comfy Cloud اجرا می‌شوند. اگر GPU ندارید یا می‌خواهید هیچ برپاسازی‌ای لازم نباشد، از همان استفاده کنید ([مقایسهٔ کنار هم](/docs/local-vs-comfy-cloud)). `comfyui-mcp` یک حالت ابری جامعه‌محور (`COMFYUI_API_KEY`) هم دارد، پس یک MCP واحد می‌تواند هر سه شکل استقرار را از یک پیکربندی هدف بگیرد — هرکدام که با گردش‌کار شما جور است انتخاب کنید.
