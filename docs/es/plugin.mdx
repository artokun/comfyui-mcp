`comfyui-mcp` no es solo un servidor MCP — se entrega como un **plugin de
Claude Code** completo. Instalar el plugin le da a Claude conocimiento
experto y específico de cada modelo sobre ComfyUI para que elija el sampler,
el CFG, la resolución y los archivos de modelo correctos sin prueba y error.

```bash
# In Claude Code
/plugin marketplace add artokun/comfyui-mcp
/plugin install comfy
```

## 39 skills de IA — y creciendo

Las skills son documentos de conocimiento curados que Claude carga bajo
demanda. Cada familia de modelos recibe parámetros de generación, grafos de
nodos, URLs curadas de descarga de modelos y guía de modos de fallo:

Las skills nuevas llegan con cada versión — generadas a partir de packs
populares del registro mediante la herramienta integrada `list_packs`
(`action: "generate_skill"`), y luego curadas por humanos.

**Prueba el conocimiento antes de cablear nada** — cada skill es un archivo
markdown plano, útil por sí solo. El más aplicable en general es
[`prompt-engineering`](https://github.com/artokun/comfyui-mcp/blob/main/plugin/skills/prompt-engineering/SKILL.md)
— el límite de 77 tokens de CLIP y el troceado `BREAK`, la sintaxis de
pesos y la estrategia por arquitectura (por qué Flux quiere lenguaje natural
y ningún prompt negativo mientras que SD1.5 quiere tags). Léelo en el
navegador, o pégalo en el contexto de cualquier agente como system prompt —
no hace falta ComfyUI, MCP ni instalación. Cuando conectes el plugin
completo, los agentes cargan los mismos archivos automáticamente
(`list_packs` con `action: "skill_read"`).

### Búsqueda en Civitai — integrada

`download_model` `action:"search_civitai"` busca en Civitai de forma nativa
(API REST pública, sin clave, sin servidor extra): filtros de palabra clave +
`types` + `base_models` («un LoRA de **Flux**»), solo SFW por defecto, y cada
resultado devuelve el `model_version_id` que `action:"download_civitai"` toma
directamente — más las **palabras disparadoras** del modelo para el prompt.
Como es una herramienta de primera clase funciona en **todos los backends**,
incluidos los modelos locales pequeños detrás del router compacto. La skill
`civitai` enseña el relevo completo de descubrimiento → descarga → generación.

**Clave API opcional.** La búsqueda no necesita ninguna. `CIVITAI_API_TOKEN`
desbloquea descargas restringidas/de acceso anticipado y resultados de
búsqueda restringidos — una sola variable alimenta tanto la búsqueda como la
descarga.

**Opcional: el Civitai MCP oficial.** Para la superficie comunitaria más allá
de buscar→instalar (navegar imágenes de ejemplo + sus parámetros de
generación, publicar, colecciones), empareja el
[servidor remoto oficial](https://mcp.civitai.com/mcp) de Civitai
— ya no se incluye automáticamente, añádelo una vez:

```bash
claude mcp add --transport http civitai https://mcp.civitai.com/mcp \
  --header "Authorization: Bearer YOUR_CIVITAI_API_KEY"
```

## 11 comandos slash

`/comfy:gen` (generar a partir de un prompt), `/comfy:debug` (diagnosticar un
flujo de trabajo fallido), `/comfy:install` (instalar packs de nodos),
`/comfy:viz` (flujo de trabajo → Mermaid), `/comfy:batch`, `/comfy:compare`,
`/comfy:convert`, `/comfy:gallery`, `/comfy:recipe`, `/comfy:director`,
`/comfy:node-skill`.

## 4 agentes autónomos

- **comfy-explorer** — profundiza en el código fuente de un pack de nodos para documentarlo
- **comfy-researcher** — enunciado del problema → recomendaciones de packs ordenadas
- **comfy-debugger** — encuentra la causa raíz de flujos de trabajo fallidos a partir del historial + registros
- **comfy-optimizer** — ajuste de VRAM y velocidad para una GPU dada

## El panel lateral — sin claves API

<Note>
  El panel lateral se entrega como pack propio, **en el Comfy Registry y en
  ComfyUI-Manager como `comfyui-agent-panel`** — búscalo ahí y elige
  **Latest**, no Nightly. Guía completa: [Panel lateral](/docs/es/panel).
</Note>

La barra lateral de [comfyui-mcp-panel](https://github.com/artokun/comfyui-mcp-panel)
ejecuta un agente autónomo con tu **suscripción de Claude** (sin facturación
API por token). Instala el pack, abre la pestaña Agente y pulsa **Conectar**
— arranca el [orquestador del panel](/docs/es/configuration) bajo demanda;
pídele una imagen, un flujo de trabajo o un cambio y trabaja contra tu
ComfyUI.

## Hooks

Tres hooks mantienen las sesiones de generación ajustadas: **comprobaciones
previas de VRAM** antes de encolar un flujo de trabajo, **notificaciones de
finalización de trabajo** y **avisos de guardado** antes de operaciones
destructivas.
