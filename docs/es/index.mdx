**ComfyUI MCP** es el **plano de control local-first y nativo para agentes** de
[ComfyUI](https://github.com/comfyanonymous/ComfyUI) — un servidor
[MCP](https://modelcontextprotocol.io) y plugin de Claude Code. Conecta tu asistente de IA a una
instancia de ComfyUI en ejecución — **local**, **remota** o
**[Comfy Cloud](https://cloud.comfy.org)** — para que puedas generar imágenes, video y audio,
ejecutar y crear flujos de trabajo, gestionar modelos y nodos personalizados, y controlar el
servidor, todo en lenguaje natural. No es un simple puente de prompt a imagen: es un agente
completo que opera ComfyUI por ti.

## Alcance: local, remoto o Comfy Cloud

`comfyui-mcp` es el MCP de la comunidad para ComfyUI **local** y **remoto** — ese es su objetivo
principal (instalaciones en Mac/Linux/Windows, RunPod, VPS, LAN, etc.).

Para los usuarios de **Comfy Cloud**, Comfy-Org ofrece [herramientas oficiales para agentes](https://docs.comfy.org/agent-tools) — Comfy Cloud MCP (beta pública) y el Comfy In-App Agent (alfa privada) — mantenidas por el equipo de Comfy y ejecutadas en Comfy Cloud. Si no tienes GPU o quieres cero configuración, usa eso ([comparativa lado a lado](/docs/local-vs-comfy-cloud)). `comfyui-mcp` también incluye un modo nube de la comunidad (`COMFYUI_API_KEY`), así que un solo MCP puede apuntar a las tres formas de despliegue desde una única configuración — elige la que encaje con tu forma de trabajar.
