## 本頁涵蓋什麼

**整個專案，不是某一個儲存庫。** comfyui-mcp 是幾塊分開出貨、獨立版本的東西：

| 部分 | 儲存庫 | 它是什麼 |
|---|---|---|
| **MCP 伺服器 + 外掛** | [`comfyui-mcp`](https://github.com/artokun/comfyui-mcp) | 工具和協調器 —— 控制平面 |
| **面板** | [`comfyui-mcp-panel`](https://github.com/artokun/comfyui-mcp-panel) | ComfyUI 裡的代理側邊欄 |
| **手機 App** | [`comfyui-mcp-mobile`](https://github.com/artokun/comfyui-mcp-mobile) | 聊天、佇列、LoRA 以及桌面分頁鏡像 |
| **中繼** | [`comfyui-mcp-relay`](https://github.com/artokun/comfyui-mcp-relay) | 給穩定 `wss://` 遠端橋接用的 Cloudflare Worker |

下面的條目在有必要時按部分標註。即便落地在四個地方，規劃時仍當作一個產品。

<Warning>
  [怎麼走到今天](#怎麼走到今天) 裡的版本號是 **MCP 伺服器的**。面板和手機 App
  走各自無關的版本線 —— 面板 0.9.x 並不是「落後於」伺服器 v0.44。別拿它們比。
</Warning>

## 怎麼讀

**本頁沒有日期，這是故意的。**

這個專案出貨很快，也經常重排 —— RunPod 這條線一週之內就插到了佇列前面。一份標了季度
的路線圖幾天就會錯，而錯的日期比沒有日期更糟：它把計劃變成了沒人做過的承諾。

所以本頁承諾的是**順序，不是時機**。「下一步」是排隊下一項，不是下個月。如果這裡有
對你重要的東西，請到 [Discord](https://discord.gg/cW9arBhzCu) 說 —— 人們每天真正在
做的事，比請求的嗓門更能把條目往上推。

最有用的一節大概是最後一節。**[不計劃做](#不計劃做)** 寫明我們決定*反對*什麼以及
為什麼，這樣你就不用再等它。

## 已發布

這裡的每一項今天都能用，並且有文件涵蓋。

| 領域 | 你得到什麼 |
|---|---|
| **ComfyUI 裡的代理** | 面板把代理放在畫布旁邊 —— 它讀節點圖、編輯節點、跑工作流程，並解釋失敗。請看[面板](/docs/zh-TW/panel)。 |
| **帶上你自己的模型** | Claude、ChatGPT/Codex、Gemini、Antigravity、Grok、Kimi、GLM、Ollama、LM Studio、llama.cpp、OpenRouter，或自訂端點 —— 一個選擇器，一個協調器。請看[後端](/docs/zh-TW/backends)。 |
| **本機模型** | 透過 Ollama / LM Studio / llama.cpp 完全本機執行，包括小型模型。請看[本機 LLM](/docs/zh-TW/local-llms)。 |
| **工作流程編寫** | 用自然語言構建、打補丁、切片、校驗並鎖定工作流程；從圖片中繼資料匯入。 |
| **模型與自訂節點** | 搜尋、安裝和修復節點包；查詢並下載模型 —— 包括算出工作流程缺哪些模型、哪種量化適合你的VRAM。 |
| **Civitai 瀏覽器** | 在面板裡瀏覽圖片、影片和模型，按基礎模型和創作者篩選，並把工作流程直接拉到畫布上。 |
| **手機 App** | 和代理聊天、看佇列、瀏覽 LoRA，並鏡像桌面分頁，用手機驅動你的機器。請看[手機](/docs/zh-TW/mobile)。 |
| **應用（微應用）** | 把工作流程變成帶真實表單的一鍵應用：在面板裡轉換並發布，在本機或執行個體上跑，從公共登錄庫安裝別人的應用 —— 同一套應用也能從手機的 Apps 分頁或透過 `apps_*` 工具由代理執行。請看[應用](/docs/zh-TW/apps)。 |
| **遠端與雲端** | 把面板指向遠端 ComfyUI、自架中繼或 Comfy Cloud。請看[遠端連接器](/docs/zh-TW/remote-connector)。 |
| **RunPod 執行個體** | 從面板建立、連線並停止 RunPod 執行個體，帶計費安全的預設值和誠實的主機指示。 |
| **LoRA 訓練（本機）** | 在 FLUX.1-dev 上練角色 LoRA，由代理透過 GPU Docker 容器裡的 `train_*` 工具驅動 —— 資料集進，`.safetensors` 從 `models/loras/` 出。 |

## 考慮中

想做，但卡在設計問題上，不是卡在工作量上。沒有承諾。

### 多使用者工作階段

讓別人連上*你的*工作階段、驅動*你的*機器 —— 結對除錯一條壞掉的工作流程，或共用一台工作室
機器。

值得把卡點說清楚，因為它不是那個顯而易見的：
**傳輸已經存在。** 配對、通訊端扇出和按工作階段的驗證，都是為手機到桌面鏡像建的，那是同一套
管道。

缺的是**信任模型**。誰被允許驅動？他們能看到你畫布、歷史、檔案系統的哪些部分？怎麼在
跑到一半時復原某人的存取？這些問題需要先答完再動手 —— 在別人的 GPU 上發布一份半成品
答案，是傷人的方式。

## 不計劃做

已經決定不做，並寫明理由，這樣沒人會空等。不是永久的 —— 好的論證會重開其中任何一項
—— 但這裡沒有排隊的東西。

### 日期和帶版本號的里程碑

請看[本頁開頭](#怎麼讀)。順序，不是時機。

### 純語音控制（智慧眼鏡、頭戴裝置）

用眼鏡語音驅動桌面代理經常被提起，管道也大體能重用鏡像傳輸。

沒排隊的原因是：純語音介面**沒有畫布**。沒有可以掃一眼的預覽，沒法在載入了兩個 LoRA
時消解「用另一個 LoRA」，代理把節點圖做錯時也沒有可見的復原。這些才是真正的問題，
加一個麥克風解決不了其中任何一個。在有答案之前，這會作為一份不好相依的演示發出去。

### 智慧手錶

上面那些全部適用，再疊上更小的螢幕和更緊的電量預算。還沒有人描述過它比手機已經在做的
事情做得更好的一份工作。

### 替你執行 ComfyUI 的託管服務

本專案是**本機優先的控制平面**。它連到你的 ComfyUI —— 在你的機器、遠端盒子、執行個體或
Comfy Cloud 上 —— 並且不想要你的檔案或提示。替你跑推理是另一種產品、另一套信任模型，
不是這個。

## 怎麼走到今天

到目前為止的弧線，給下一批條目提供上下文。故意寫得很粗 —— 某次發布具體改了什麼，見
[更新記錄](/docs/changelog)。

<Note>
  公開發布從 **v0.2.0** 開始。沒有 v0.0.1 或 v0.1.x —— 頭兩週的工作直接落在 `main`
  上，包發布之前就開始了，從 **2026-02-15** 的初始提交算起。
</Note>

所示發布是 **MCP 伺服器的** —— 面板和手機 App 分開版本，下面的時代描述的是整個
專案。

| 時代 | 伺服器發布 | 它在做什麼 |
|---|---|---|
| **MCP 伺服器**<br/>2026 年 2 月 | v0.2 – v0.3 | 最初的想法：用代理驅動 ComfyUI。圖片生成、工作流程分析、UI→API 工作流程轉換器、分層視覺化、模型技能，以及從阻塞執行轉到帶背景進度和行程控制的非阻塞佇列。 |
| **安靜的一段**<br/>2026 年 3 – 4 月 | v0.3.x | 兩個月裡三個功能提交。透過 HTTP 的遠端 ComfyUI、轉換器裡的子圖 / 元件展開、HTTPS/WSS 支援。地基，不是頭條。 |
| **環境與生命週期**<br/>2026 年 5 月 | v0.4 – v0.8 | 讓它在真實安裝裡活下來：帶 CI 的自訂節點校驗 / 腳手架、釘到 git ref 的安裝、門禁和私有模型的驗證、宣告式環境清單、雲端儲存提供商、服務端影像轉換，以及快取的節點技能發現。內嵌面板在這段末尾設計出來。 |
| **面板時代**<br/>2026 年 6 月 | v0.9 – v0.22 | 按體量最大的一個月（約 102 個功能提交）。代理*走進* ComfyUI、待在畫布旁邊，拿到多個供應商，並長出能在任何地方跑的基礎設施：一鍵安裝包、RunPod 映像檔、帶選用中繼的安全 `wss://` 橋接，以及即時推理可見性。 |
| **觸達與深度**<br/>2026 年 7 月 | v0.23 – v0.44 | 兩個方向同時推進。**觸達：** 手機 App、桌面分頁鏡像、Civitai 瀏覽器、更多供應商（Antigravity、GLM、Kimi），以及讓小型本機模型能驅動工具的精簡工具模式。**深度：** LLM 競技場、帶計費安全預設值的官方 RunPod 執行個體、LoRA 訓練，以及會考慮你的 VRAM的缺失模型解析。 |

那張表不會告訴你兩件事。節奏故意不均勻 —— 春天兩個月的靜默，然後六七月大約 180 個
功能提交。排序也從來沒有提前釘死：RunPod 和訓練都插隊了，因為它們後來比名義上下一項
更重要。這也是本頁不帶日期的主要原因。
