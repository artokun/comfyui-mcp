**ComfyUI MCP** 是 [ComfyUI](https://github.com/comfyanonymous/ComfyUI) 的**本機優先、代理原生控制平面**
—— 一個 [MCP](https://modelcontextprotocol.io) 伺服器，同時也是 Claude Code 外掛。它把你的 AI 助理
連上正在執行的 ComfyUI 實例 —— **本機**、**遠端**或 **[Comfy Cloud](https://cloud.comfy.org)** ——
讓你用自然語言生成圖片、影片與音訊，執行並撰寫工作流程，管理模型與自訂節點，還能控制伺服器。
它不是單薄的「提示詞轉圖片」橋接，而是一個替你操作 ComfyUI 的完整代理。

## 適用範圍：本機、遠端或 Comfy Cloud

`comfyui-mcp` 是面向**本機**與**遠端** ComfyUI 的社群 MCP —— 這就是它的主要對象
（Mac/Linux/Windows 上的安裝、RunPod、VPS、區域網路等）。

給 **Comfy Cloud** 使用者：Comfy-Org 提供了[官方代理工具](https://docs.comfy.org/agent-tools) —— Comfy Cloud MCP（公開 Beta）與 Comfy In-App Agent（私人 Alpha）—— 由 Comfy 團隊維護，並執行在 Comfy Cloud 上。如果你沒有 GPU，或想要零設定就開始，就用那一套（[並列比較](/docs/local-vs-comfy-cloud)）。`comfyui-mcp` 也內建了社群版的雲端模式（`COMFYUI_API_KEY`），所以單一個 MCP 就能從同一份設定指向這三種部署形態 —— 挑最合你工作方式的那一種。
