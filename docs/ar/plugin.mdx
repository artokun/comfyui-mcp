`comfyui-mcp` ليس مجرّد خادم MCP — بل يُشحن **إضافة Claude Code** كاملة.
تثبيت الإضافة يمنح Claude معرفة خبيرة خاصة بالنماذج عن ComfyUI فيختار العيّنة
الصحيحة وCFG والدقة وملفات النماذج دون تجريب وخطأ.

```bash
# In Claude Code
/plugin marketplace add artokun/comfyui-mcp
/plugin install comfy
```

## 39 مهارة ذكاء اصطناعي — وما زالت تنمو

المهارات وثائق معرفة منتقاة يحمّلها Claude عند الحاجة. وتحصل كل عائلة نماذج
على معاملات التوليد ومخططات العقد وروابط تنزيل منتقاة وإرشاد لأنماط الفشل:

| `anima-base` | ANIMA 1.0 — نموذج أنمي/رسوم بنحو 2B، ووسوم Danbooru + لغة طبيعية، وطلاء أنمي، بأقل من 6 غيغابايت من ذاكرة VRAM |

| `troubleshooting` | نفاد الذاكرة، والعقد الناقصة، وانحراف الإصدارات — أشجار تشخيص |
| `comfyui-launch-flags` | مصفوفة رايات التشغيل لذاكرة VRAM/الانتباه/التخزين المؤقّت/الأداء — `--reserve-vram`، و`--novram`+`--cache-none`، و`--use-sage-attention` مقابل `--use-pytorch-cross-attention` (Z-Image)، إضافةً إلى ملاحظات مكدّس التسريع لـ Blackwell/RTX 5000 |

تهبط مهارات جديدة مع كل إصدار — مولَّدة من حزم السجل الشائعة عبر أداة
`list_packs` المدمجة (`action: "generate_skill"`)، ثم ينتقيها إنسان.

**جرّب المعرفة قبل توصيل أي شيء** — كل مهارة ملف markdown عادي، مفيد وحده.
وأوسعها تطبيقًا هي
[`prompt-engineering`](https://github.com/artokun/comfyui-mcp/blob/main/plugin/skills/prompt-engineering/SKILL.md)
— حدّ CLIP البالغ 77 رمزًا وتقطيع `BREAK`، وصياغة الأوزان، والاستراتيجية حسب
المعمارية (لماذا يريد Flux لغة طبيعية بلا موجّه سلبي بينما يريد SD1.5 وسومًا).
اقرأها في المتصفح، أو الصقها في سياق أي وكيل كموجّه نظام — بلا حاجة إلى
ComfyUI أو MCP أو تثبيت. وعندما تصل الإضافة كاملة، تحمّل الوكلاء الملفات نفسها
تلقائيًا (`list_packs` مع `action: "skill_read"`).

### البحث في Civitai — مدمج

يبحث `download_model` `action:"search_civitai"` في Civitai أصليًا (واجهة REST
عامة، بلا مفتاح، بلا خادم إضافي): كلمة مفتاحية + عوامل `types` + `base_models`
(«ملف LoRA لـ **Flux**»)، وآمن للعرض افتراضيًا، وكل نتيجة تُرجع
`model_version_id` الذي يأخذه `action:"download_civitai"` مباشرة — إضافةً إلى
**كلمات تشغيل** النموذج للموجّه. ولأنه أداة من الدرجة الأولى يعمل على **كل
خلفية**، بما فيها النماذج المحلية الصغيرة خلف الموجّه المضغوط. وتعلّم مهارة
`civitai` تسليم الاكتشاف → التنزيل → التوليد كاملًا.

**مفتاح API اختياري.** البحث لا يحتاج إلى أي مفتاح. ويفتح `CIVITAI_API_TOKEN`
التنزيلات المحجوبة/ذات الوصول المبكر ونتائج البحث المحجوبة — متغيّر واحد يشغّل
البحث والتنزيل معًا.

**اختياري: Civitai MCP الرسمي.** لسطح المجتمع وراء البحث→التثبيت (تصفّح صور
الأمثلة + معاملات توليدها، والنشر، والمجموعات)، اقرن
[الخادم البعيد الرسمي](https://mcp.civitai.com/mcp) لدى Civitai
— لم يعد يُضمَّن تلقائيًا، أضِفه مرة واحدة:

```bash
claude mcp add --transport http civitai https://mcp.civitai.com/mcp \
  --header "Authorization: Bearer YOUR_CIVITAI_API_KEY"
```

## 11 أمرًا مختصرًا

`/comfy:gen` (ولّد من موجّه)، `/comfy:debug` (شخّص سير عمل فاشل)،
`/comfy:install` (ثبّت حزم العقد)، `/comfy:viz` (سير عمل → Mermaid)،
`/comfy:batch`، `/comfy:compare`، `/comfy:convert`، `/comfy:gallery`،
`/comfy:recipe`، `/comfy:director`، `/comfy:node-skill`.

## 4 وكلاء مستقلين

- **comfy-explorer** — يغوص في مصدر حزمة عقد لتوثيقها
- **comfy-researcher** — بيان مشكلة → توصيات حزم مرتَّبة
- **comfy-debugger** — يتتبّع جذور مسارات العمل الفاشلة من السجل + اللوجات
- **comfy-optimizer** — ضبط ذاكرة VRAM والسرعة لوحدة GPU معيّنة

## اللوحة الجانبية — بلا مفاتيح API

<Note>
  تُشحن اللوحة الجانبية كحزمة مستقلة، **على Comfy Registry وفي
  ComfyUI-Manager باسم `comfyui-agent-panel`** — ابحث عنها هناك واختر
  **Latest**، لا Nightly. الدليل الكامل: [اللوحة الجانبية](/docs/ar/panel).
</Note>

يشغّل الشريط الجانبي [comfyui-mcp-panel](https://github.com/artokun/comfyui-mcp-panel)
وكيلًا مستقلًا على **اشتراك Claude** لديك (بلا فوترة API لكل رمز). ثبّت الحزمة،
وافتح تبويب الوكيل، وانقر **اتصال** — فيبدأ
[منسّق اللوحة](/docs/ar/configuration) عند الطلب؛ اطلب منه صورة أو سير عمل أو
تعديلًا فيعمل على ComfyUI لديك.

## الخطافات

ثلاثة خطافات تُبقي جلسات التوليد محكمة: **فحوصات VRAM المسبقة** قبل إدراج سير
عمل في قائمة الانتظار، و**إشعارات اكتمال المهام**، و**تحذيرات الحفظ** قبل
العمليات المدمِّرة.
