إن كنت تختار بين أدوات الوكلاء الرسمية من Comfy-Org وهذا المشروع، فالخلاصة
أن **كلًا منهما يحل مشكلة مختلفة** — وبالنسبة لعدد لا بأس به من الناس فإن
الخيار الرسمي هو القرار الصحيح. تعرض هذه الصفحة الاثنين بصدق حتى تختار مرة
واحدة وتمضي.

<Note>
Comfy-Org يشحن بسرعة، والحالات أدناه اعتبارًا من **يوليو 2026**. راجع
[docs.comfy.org/agent-tools](https://docs.comfy.org/agent-tools) للحالة
الحالية قبل أن تعامل أيًا من هذا على أنه محسوم.
</Note>

## الإجابة في سطر واحد

**لا توجد وحدة GPU محلية، أو تريد إعدادًا صفريًا؟** استخدم Comfy Cloud. إنه
طرف أول، ويصونه الفريق الذي يبني ComfyUI، ولا تحتاج إلى التفكير في برامج
التشغيل أو ذاكرة VRAM أو تنزيلات النماذج.

**تشغّل ComfyUI بالفعل على جهازك؟** هذا ما وُجد هذا المشروع من أجله. فوحدة
GPU لديك مدفوعة سلفًا، ونماذجك موجودة على القرص، واشتراك Claude أو ChatGPT
يغطي الاستدلال أصلًا.

## ما الذي تقدّمه Comfy-Org

تسرد صفحة [أدوات الوكلاء](https://docs.comfy.org/agent-tools) لدى Comfy-Org
ثلاثة منتجات ذات صلة:

| المنتج | ما هو | الحالة (يوليو 2026) |
|---|---|---|
| **Comfy Cloud MCP** | خادم MCP مستضاف؛ يجري التوليد على وحدات GPU في Comfy Cloud | نسخة تجريبية عامة |
| **Comfy In-App Agent** | وكيل يقوده الدردشة داخل Comfy Cloud يبني مخططك ويحرّره | نسخة ألفا خاصة |
| **Comfy Local MCP** | خادم MCP محلي من الطرف الأول يقود تثبيت ComfyUI لديك | اختبار خاص؛ غير متاح للعامة بعد |

Comfy Cloud MCP جيّد حقًا فيما يفعله: فهو يعرض محرّك ComfyUI عبر MCP، ويسجّل
الدخول بـ OAuth من Claude Code وClaude Desktop وCodex، ويمنحك وصولًا مُدارًا
إلى نماذج مثل Kling وVeo وSeedance وFlux وElevenLabs دون أن تملك وحدة GPU.

## ما الذي يقدّمه هذا المشروع

`comfyui-mcp` خادم MCP إضافةً إلى وكيل في الشريط الجانبي يقود تثبيت ComfyUI
**لديك** — محليًا أو على الشبكة المحلية أو VPS أو RunPod. 37 أداة MCP، و39
مهارة خاصة بالنماذج، ووكيل لوحة يحرّر مخططك الحيّ باللغة الطبيعية.

الفرق البنيوي هو **من أين يأتي الاستدلال**. هذا المشروع محايد تجاه المزوّد:
فالأدوات نفسها واللوحة نفسها تعملان على Claude أو ChatGPT أو Gemini أو Grok
أو Kimi باستخدام اشتراك تدفعه أصلًا، أو على أي نقطة نهاية متوافقة مع OpenAI،
أو على نموذج محلي مجاني عبر Ollama أو LM Studio أو llama.cpp — بلا حساب وبلا
شبكة صادرة على الإطلاق.

## مقارنة جنبًا إلى جنب

| | Comfy Cloud (In-App Agent / Cloud MCP) | comfyui-mcp |
|---|---|---|
| يجري التوليد على | وحدات GPU في Comfy Cloud | وحدة GPU لديك (أو VPS / Pod في RunPod) |
| يتطلّب حساب Comfy | نعم | لا |
| يعمل دون اتصال بالكامل | لا | نعم، مع نموذج محلي |
| نموذج الاستدلال | يوفّره الخدمة | **لديك** — أي نموذج لغوي، بما فيه المحلي المجاني |
| نموذج التكلفة | أرصدة سحابية | اشتراكك الحالي، أو 0$ محليًا |
| تغادر صورك/موجّهاتك الجهاز | نعم | فقط إن اخترت نموذجًا لغويًا مستضافًا |
| يدير عقدك المخصّصة وملفات النماذج | غير منطبق (بيئة مُدارة) | نعم — يثبّت العقد وينزّل النماذج |
| التوفّر | Cloud MCP تجريبي عام؛ الوكيل ألفا خاص | متاح الآن |
| دعم الطرف الأول | نعم | مشروع مجتمعي |

## اختر Comfy Cloud إذا…

- ليست لديك وحدة GPU، أو وحدتك أصغر من أن تشغّل النماذج التي تريدها
- تريد أن يعمل دون إعداد ودون صيانة
- تفضّل شراء أرصدة على إدارة CUDA وVRAM وتنزيلات ملفات Checkpoint
- فريقك موجود أصلًا على Comfy Cloud وتريد مورّدًا واحدًا وفاتورة واحدة
- تريد دعم الطرف الأول من الذين يبنون ComfyUI

هذه أسباب وجيهة. إن انطبق عليك عدّة منها، توقّف عن القراءة واستخدم
[Comfy Cloud](https://comfy.org/) — ستكون تجربتك أفضل.

## اختر comfyui-mcp إذا…

- **لديك وحدة GPU أصلًا.** لقد دفعت ثمنها؛ والأرصدة السحابية فاتورة ثانية
  لحساب تملكه.
- **لا يمكن لعملك أن يغادر الجهاز.** مواد عميل تحت اتفاقية سرّية، أو بيانات
  تدريب مرخّصة، أو أي شيء لا يمكنك رفعه. ومع نموذج محلي لا يغادر شيء.
- **تريد استخدام اشتراك النموذج اللغوي الذي لديك أصلًا.** فخطة Claude أو
  ChatGPT تغطي الاستدلال أصلًا — بلا عدّاد ثانٍ للوكيل.
- **تريده مجانيًا، أو تريده دون اتصال.** Ollama وLM Studio وllama.cpp تعمل
  بلا حساب وبلا شبكة. راجع [النماذج المحلية](/docs/ar/local-llms).
- **تثبيتك هو الغاية.** عقدك المخصّصة، وملفات LoRA لديك، ومجموعة ملفات
  Checkpoint. ي[ثبّت الوكيل العقد وينزّل النماذج](/docs/tools/models) في
  التثبيت الذي تستخدمه فعلًا.
- **تريد اختيار النموذج.** تختلف النماذج اللغوية في ما تجيده؛ و[حلبة
  النماذج اللغوية](/docs/ar/arena) تقيّمها على مهام ComfyUI حقيقية حتى
  تختار بالدليل. راجع [الخلفيات](/docs/ar/backends).

## «ألن يجعل MCP المحلي الرسمي هذا المشروع زائدًا؟»

سؤال عادل، ويستحق إجابة مباشرة بدل التظاهر بغير ذلك.

Comfy Local MCP هو **سائق طرف أول لتثبيت محلي**، وعندما يُشحن سيكون جيّدًا.
لكنه طبقة مختلفة عن هذا المشروع: فهو يصل وكيلًا بـ ComfyUI، حيث يجلب
`comfyui-mcp` الوكيل أيضًا، والخلفية المحايدة تجاه المزوّد التي تشغّله عبر
أحد عشر مزوّدًا وبيئات تشغيل محلية، وواجهة الشريط الجانبي، ومهارات النماذج،
وإدارة العقد/النماذج.

القراءة الصادقة: إن كان كل ما تريده هو «دع Claude Code يتحدّث إلى ComfyUI
المحلي لدي»، فستغطّي أدوات الطرف الأول ذلك في النهاية، وينبغي أن تستخدمها
على الأرجح. أمّا إن أردت إحضار نموذجك — بما فيه نموذج محلي مجاني — وأن يعيش
الوكيل داخل ComfyUI ويدير التثبيت نفسه، فهذه هي الفجوة التي وُجد هذا المشروع
ليسدّها.

وهما يتكاملان أيضًا. يستطيع هذا المشروع استهداف Comfy Cloud كذلك (اضبط
`COMFYUI_API_KEY` — راجع [النشر السحابي](/docs/ar/cloud-deployment))، فيغطّي
إعداد واحد تثبيتًا محليًا وجهازًا على الشبكة المحلية وخادم VPS وComfy Cloud.
