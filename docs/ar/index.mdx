**ComfyUI MCP** هو **مستوى التحكّم المحلي أولًا والمصمَّم أصلًا للوكلاء** الخاص بـ
[ComfyUI](https://github.com/comfyanonymous/ComfyUI) — خادم [MCP](https://modelcontextprotocol.io)
وإضافة لـ Claude Code. يربط مساعدك الذكي بنسخة ComfyUI قيد التشغيل — **محلية** أو **بعيدة** أو على
**[Comfy Cloud](https://cloud.comfy.org)** — فتولّد الصور والفيديو والصوت، وتشغّل مسارات سير العمل
وتؤلّفها، وتدير النماذج والعقد المخصّصة، وتتحكّم في الخادم، وكل ذلك باللغة الطبيعية. ليس جسرًا سطحيًا
من الموجّه إلى الصورة — بل وكيل كامل يشغّل ComfyUI نيابةً عنك.

## النطاق: محلي أو عن بُعد أو Comfy Cloud

`comfyui-mcp` هو MCP المجتمعي لـ ComfyUI **المحلي** و**البعيد** — وهذا هو الهدف الأساسي (تثبيتات
Mac/Linux/Windows، وRunPod، وخوادم VPS، والشبكة المحلية، وغيرها).

لمستخدمي **Comfy Cloud**، تقدّم Comfy-Org [أدوات وكلاء رسمية](https://docs.comfy.org/agent-tools) — Comfy Cloud MCP (نسخة تجريبية عامة) وComfy In-App Agent (نسخة ألفا خاصة) — يصونها فريق Comfy وتعمل على Comfy Cloud. إن لم تكن لديك وحدة GPU أو أردت إعدادًا صفريًا، فاستخدمها ([مقارنة جنبًا إلى جنب](/docs/local-vs-comfy-cloud)). كما يتضمّن `comfyui-mcp` وضعًا سحابيًا مجتمعيًا (`COMFYUI_API_KEY`)، فيستطيع MCP واحد استهداف أشكال النشر الثلاثة كلها من إعداد واحد — اختر ما يناسب طريقة عملك.
