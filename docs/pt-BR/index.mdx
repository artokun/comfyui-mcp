**ComfyUI MCP** é o **plano de controle local-first e nativo para agentes** do
[ComfyUI](https://github.com/comfyanonymous/ComfyUI) — um servidor
[MCP](https://modelcontextprotocol.io) e plugin do Claude Code. Ele conecta o seu assistente de IA
a uma instância do ComfyUI em execução — **local**, **remota** ou
**[Comfy Cloud](https://cloud.comfy.org)** — para que você possa gerar imagens, vídeo e áudio,
executar e criar workflows, gerenciar modelos e nós personalizados, e controlar o servidor, tudo
em linguagem natural. Não é uma ponte simples de prompt para imagem — é um agente completo que
opera o ComfyUI por você.

## Escopo: local, remoto ou Comfy Cloud

O `comfyui-mcp` é o MCP da comunidade para ComfyUI **local** e **remoto** — esse é o alvo
principal (instalações em Mac/Linux/Windows, RunPod, VPS, LAN etc.).

Para quem usa o **Comfy Cloud**, a Comfy-Org oferece [ferramentas oficiais para agentes](https://docs.comfy.org/agent-tools) — o Comfy Cloud MCP (beta pública) e o Comfy In-App Agent (alfa privada) — mantidas pelo time da Comfy e executadas no Comfy Cloud. Se você não tem GPU ou quer configuração zero, use isso ([comparativo lado a lado](/docs/local-vs-comfy-cloud)). O `comfyui-mcp` também inclui um modo nuvem da comunidade (`COMFYUI_API_KEY`), então um único MCP consegue atingir os três formatos de implantação a partir de uma só configuração — escolha o que se encaixa no seu jeito de trabalhar.
