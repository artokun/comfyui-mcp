**이 프로젝트는 더 이상 유지보수되지 않습니다.** ComfyUI는 이제 Comfy-Org 팀이 만들고 지원하는 공식 에이전트 및 MCP 도구인 **Comfy Agent**와 **Comfy MCP**를 제공합니다. 공식 도구를 사용해 주세요: [Agent tools docs](https://docs.comfy.org/agent-tools) · [Comfy MCP](https://comfy.org/mcp/) · [Comfy-Org/comfy-mcp](https://github.com/Comfy-Org/comfy-mcp). 이 사이트는 참고용으로만 유지되며 새로운 기능, 버그 수정, 의존성 업데이트는 없습니다.
</Warning>

**ComfyUI MCP**는 [ComfyUI](https://github.com/comfyanonymous/ComfyUI)를 위한 **로컬 우선, 에이전트
네이티브 컨트롤 플레인**입니다 — [MCP](https://modelcontextprotocol.io) 서버이자 Claude Code
플러그인입니다. 실행 중인 ComfyUI 인스턴스 — **로컬**, **원격**, 또는
**[Comfy Cloud](https://cloud.comfy.org)** — 에 AI 어시스턴트를 연결해, 이미지·동영상·오디오를
생성하고, 워크플로우를 실행·작성하고, 모델과 커스텀 노드를 관리하고, 서버를 제어하는 일을 모두
자연어로 할 수 있게 해줍니다. 단순한 프롬프트-투-이미지 브리지가 아니라, ComfyUI를 대신 운영해주는
완전한 에이전트입니다.

## 범위: 로컬, 원격, 또는 Comfy Cloud

`comfyui-mcp`는 **로컬**과 **원격** ComfyUI를 위한 커뮤니티 MCP입니다 — 이것이 주요 대상입니다
(Mac/Linux/Windows 설치, RunPod, VPS, LAN 등).

**Comfy Cloud** 사용자를 위해 Comfy-Org는 Comfy 팀이 유지 관리하며 Comfy Cloud에서 실행되는
[공식 에이전트 툴링](https://docs.comfy.org/agent-tools) — Comfy Cloud MCP(퍼블릭 베타)와
Comfy In-App Agent(프라이빗 알파) — 을 제공합니다. GPU가 없거나 설정을 전혀 하고 싶지 않다면
이를 사용하세요 ([나란히 비교](/docs/local-vs-comfy-cloud)). `comfyui-mcp`에도 커뮤니티 클라우드
모드(`COMFYUI_API_KEY`)가 포함되어 있어, 하나의 MCP로 세 가지 배포 형태를 모두 하나의 설정에서
대상으로 삼을 수 있습니다 — 본인의 작업 방식에 맞는 것을 고르세요.
