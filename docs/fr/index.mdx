**ComfyUI MCP** est le **plan de contrôle local-first et nativement agentique** de
[ComfyUI](https://github.com/comfyanonymous/ComfyUI) — un serveur
[MCP](https://modelcontextprotocol.io) et un plugin Claude Code. Il connecte votre assistant IA à
une instance ComfyUI en cours d'exécution — **locale**, **distante** ou
**[Comfy Cloud](https://cloud.comfy.org)** — pour générer des images, des vidéos et de l'audio,
exécuter et créer des workflows, gérer les modèles et les nœuds personnalisés, et piloter le
serveur, le tout en langage naturel. Pas un simple pont prompt-vers-image — un agent complet qui
exploite ComfyUI à votre place.

## Portée : local, distant ou Comfy Cloud

`comfyui-mcp` est le MCP communautaire pour ComfyUI **local** et **distant** — c'est la cible
principale (installations Mac/Linux/Windows, RunPod, VPS, LAN, etc.).

Pour les utilisateurs de **Comfy Cloud**, Comfy-Org propose un [outillage agent officiel](https://docs.comfy.org/agent-tools) — Comfy Cloud MCP (bêta publique) et Comfy In-App Agent (alpha privée) — maintenu par l'équipe Comfy et exécuté sur Comfy Cloud. Si vous n'avez pas de GPU ou que vous ne voulez aucune configuration, utilisez-le ([comparatif](/docs/local-vs-comfy-cloud)). `comfyui-mcp` inclut également un mode cloud communautaire (`COMFYUI_API_KEY`) : un seul MCP peut donc cibler les trois formes de déploiement depuis une seule configuration — choisissez celle qui correspond à votre façon de travailler.
